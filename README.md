# InstaFLEXY v1.6 🔍

Extensão para Google Chrome que permite consultar os seguidores no Instagram, identificando **quem você segue, mas não segue você de volta**.

O projeto foi desenvolvido com o objetivo de facilitar essa consulta de maneira simples e prática, diretamente pelo navegador.

## 🚀 Funcionalidades

- ❌ Identificação de usuários que não seguem você de volta.
- 🧩 Integração com o Google Chrome por meio de uma extensão.
- ⚡ Interface simples e prática.

## 🛠️ Tecnologias utilizadas

- **JavaScript** — Lógica e processamento dos dados.
- **JSON** — Configuração da extensão.
- **Chrome Extensions API** — Integração com o navegador.
- **Manifest V3** — Padrão de desenvolvimento de extensões do Chrome.

## 📦 Instalação

A extensão pode ser instalada manualmente no Google Chrome.

**1. Clone o repositório**

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

Ou baixe o projeto em **Code → Download ZIP** e extraia os arquivos.

**2. Abra as extensões do Chrome**

Digite na barra de endereços:

```text
chrome://extensions/
```

**3. Ative o modo desenvolvedor**

Habilite a opção **Modo do desenvolvedor**, localizada no canto superior direito.

**4. Carregue a extensão**

Clique em **Carregar sem compactação** e selecione a pasta do projeto que contém o arquivo.

A extensão estará disponível no navegador.

## 📖 Como utilizar

1. Acesse [Instagram](https://www.instagram.com/) e entre na sua conta.
2. Abra a extensão pelo ícone na barra de ferramentas do Chrome.
3. Inicie a consulta utilizando o mecanismo disponibilizado pela extensão.
4. Aguarde a coleta dos dados.
5. Consulte os perfis que você segue, mas que não seguem você de volta.

> **Nota:** O funcionamento depende da disponibilidade das informações fornecidas pelo Instagram. Alterações na plataforma podem afetar a extensão.

## 🔒 Privacidade e segurança

Este projeto foi criado para facilitar a análise das relações de seguidores de uma conta do Instagram.

Recomenda-se revisar as permissões solicitadas pela extensão e evitar compartilhar credenciais, cookies de sessão ou dados pessoais.

A extensão é um projeto independente e **não possui vínculo oficial com Instagram ou Meta**.

## ⚠️ Aviso importante

Este projeto possui finalidade educacional e de uso pessoal.

O Instagram pode alterar suas interfaces, mecanismos de acesso e políticas de utilização a qualquer momento, afetando o funcionamento da extensão.

Utilize a ferramenta com responsabilidade e respeite os termos de uso da plataforma.
